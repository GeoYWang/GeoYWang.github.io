Sending Me Encrypted Mail

  1. Thunderbird has OpenPGP built in since version 78, so no add-on is needed. Download geo.asc, open Tools → OpenPGP Key Manager, then File → Import Public Key(s) From File. When writing to me, turn on Encrypt in the compose window.
  2. Command line: gpg --import geo.asc, then gpg --fingerprint geo.wang@nyu.edu.
  3. Other clients such as Kleopatra or GPG Suite can import the same file.

Whichever you use, check that the fingerprint matches the one above before trusting the key.
